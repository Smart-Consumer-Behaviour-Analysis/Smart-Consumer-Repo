# 02 – Data Collection

This stage records where the consumer behaviour data comes from and how it was obtained.

## Store here
- Dataset acquisition notes
- Source links and citations
- Data collection scripts, if used
- Original dataset documentation

## Guidelines
- Keep original files in `data/raw/`.
- Do not overwrite raw data during cleaning.
- Record the source, date accessed, license or permission, coverage, and known limitations in the root `data_sources.md`.
- Do not upload personal, confidential, or restricted data.

## Completion checklist
- [ ] Dataset selected and approved
- [ ] Source documented
- [ ] Data access and usage permission checked
- [ ] Data fields described in the data dictionary
