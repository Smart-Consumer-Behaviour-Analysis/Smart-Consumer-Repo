# Analysis Notebooks

Store Jupyter notebooks for data inspection, preprocessing experiments, exploratory analysis, and reproducible visualizations.

Recommended naming:
- `01_data_inspection.ipynb`
- `02_data_cleaning.ipynb`
- `03_exploratory_analysis.ipynb`
- `04_visualization.ipynb`

Restart the kernel and run all cells before committing a notebook. Avoid storing private data or credentials in notebook outputs.
