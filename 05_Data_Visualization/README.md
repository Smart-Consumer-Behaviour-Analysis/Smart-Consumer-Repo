# 05 – Data Visualization

This stage turns verified analysis results into understandable charts.

## Possible outputs
- Category and segment comparisons
- Distributions and frequency charts
- Time-based trends, if dates are available
- Relationships between variables
- Summary KPI visuals

Save exported chart files in `visualizations/`. Include descriptive titles, readable labels, units, legends where needed, and a short explanation of what each chart shows.

## Completion checklist
- [ ] Every chart answers a clear question
- [ ] Axes and units are labeled
- [ ] Visuals use suitable chart types
- [ ] Charts agree with the underlying analysis
