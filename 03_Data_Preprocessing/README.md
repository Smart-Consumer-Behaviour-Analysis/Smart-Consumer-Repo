# 03 – Data Preprocessing

This stage prepares the collected dataset for reliable analysis.

## Typical activities
- Inspect rows, columns, and data types.
- Identify missing values and duplicates.
- Check inconsistent labels, formats, and units.
- Validate ranges and categorical values.
- Apply documented cleaning and transformation rules.
- Save cleaned outputs in `data/processed/`.

## Reproducibility
Keep preprocessing steps in notebooks or scripts. Record the number of records before and after cleaning and explain any removed or modified values.

## Completion checklist
- [ ] Initial data inspection completed
- [ ] Missing values assessed
- [ ] Duplicates and inconsistent values assessed
- [ ] Transformations documented
- [ ] Cleaned dataset validated
