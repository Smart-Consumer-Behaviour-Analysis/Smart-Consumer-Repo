# 04 – Data Analysis

This stage explores the prepared data and answers the project's research questions.

## Typical activities
- Descriptive statistics
- Frequency and distribution analysis
- Trend and comparison analysis, where supported by the data
- Relationships between relevant variables
- Segment-level analysis, where appropriate

## Guidelines
- Use the cleaned data from `data/processed/`.
- Explain why each analysis method is appropriate.
- Keep calculations reproducible in `notebooks/` or `src/`.
- Distinguish observed patterns from assumptions; do not claim causation from correlation alone.

## Completion checklist
- [ ] Research questions mapped to analysis
- [ ] Methods and calculations documented
- [ ] Results checked
- [ ] Limitations recorded
